# SwiftWork 录屏介绍脚本（3-5 分钟）

> 目标受众：通用产品展示
> 录屏工具建议：macOS 系统录屏（Cmd+Shift+5）或 OBS
> 分辨率：录制窗口即可，建议 1280x800 或 1440x900

---

## 第一幕：开场（0:00 - 0:30）

**画面：** SwiftWork 应用全屏或居中大窗口，干净的桌面背景

**旁白：**
> SwiftWork 是一款 macOS 原生的 AI 智能体工作台。
> 它让你能实时看到 AI Agent 正在做什么、为什么这样做，以及每一步的执行结果。
> 今天我来快速演示一下它的核心功能。

**操作：** 无特别操作，展示 app 静态界面 3-5 秒

---

## 第二幕：会话管理 & 基础对话（0:30 - 1:30）

**画面：** 左侧 Sidebar + 中间 Workspace

**旁白：**
> 左边是会话列表，可以创建、重命名和删除对话。
> 每个会话独立保存，重启 app 后会恢复上次的状态。

**操作：**
1. 点击 Sidebar 底部的 **"+"** 按钮创建新会话
2. 在输入框输入一个问题，比如："用 Python 写一个快速排序算法"
3. 按 Enter 发送

**旁白（发送后）：**
> 消息发送后，Agent 的响应会实时流式输出。
> 你可以看到文本逐步显示，就像和真人对话一样。

**操作：** 等待 Agent 响应流式输出完成

---

## 第三幕：事件时间线 & Tool Card（1:30 - 2:30）

**画面：** Agent 响应中，时间线展示各种事件卡片

**旁白：**
> 这是 SwiftWork 最核心的能力——事件时间线。
> Agent 的每一步操作都被实时可视化为不同类型的事件卡片。

**操作：**
1. 指向用户消息气泡
2. 指向 Agent 的文本回复区域
3. 找到 Tool Call 卡片，点击展开

**旁白：**
> 这是工具调用卡片。你可以看到工具名称、传入参数，
> 点击展开后还能看到完整的执行结果。
> 目前支持 18 种以上的事件类型渲染。

**操作（如果 Agent 还没调用工具）：**
> 发送一个会触发工具调用的问题，比如："当前目录下有哪些文件？"
> 等待 Agent 调用 Bash 工具，展示 Tool Card

---

## 第四幕：权限控制（2:30 - 3:00）

**画面：** 触发一次需要权限批准的工具调用

**旁白：**
> 当 Agent 需要执行敏感操作时，SwiftWork 会在时间线中弹出内联审批卡片。
> 你可以选择批准本次、允许整个会话、或者拒绝。

**操作：**
1. 如果自动批准模式开启，先在设置中关闭
2. 让 Agent 执行一个需要批准的操作（如写文件）
3. 展示三种选项：Approve / Allow for Session / Deny

**旁白：**
> 你也可以在设置中配置权限规则，实现自动批准特定工具，
> 或者开启全局自动批准模式。

---

## 第五幕：Skill 技能系统（3:00 - 3:45）

**画面：** 输入框中输入 "/"

**旁白：**
> SwiftWork 内置了技能系统。在输入框中输入斜杠 "/"，
> 就会弹出可用技能的自动补全列表。

**操作：**
1. 在输入框输入 "/"
2. 展示自动补全列表
3. 选择一个技能执行（如内置测试技能）
4. 展示 Skill 时间线卡片的专属渲染

**旁白：**
> 技能按来源分组——内置技能、项目技能和用户自定义技能。
> 在设置的技能管理面板中可以浏览和管理所有已安装的技能。

---

## 第六幕：Inspector 检查面板（3:45 - 4:15）

**画面：** 三栏布局

**旁白：**
> 点击右侧的 Inspector 面板，可以看到完整的三栏布局。
> 左边是会话列表，中间是工作区，右边是事件详情。

**操作：**
1. 点击某个事件打开 Inspector
2. 展示 Inspector 中显示的详细事件信息
3. 展示面板状态持久化——切换会话再切回来，面板还在

**旁白：**
> Inspector 让你深入检查每一个事件的完整数据，
> 非常适合调试和理解 Agent 的行为。

---

## 第七幕：设置 & 收尾（4:15 - 4:45）

**画面：** 打开设置面板

**旁白：**
> 在设置中，你可以管理 API Key、选择模型、
> 配置权限规则，以及管理已安装的技能。

**操作：**
1. 打开设置（Cmd+, 或菜单）
2. 快速浏览各标签页

**旁白（收尾）：**
> SwiftWork 是完全开源的 macOS 原生应用，
> 基于 Open Agent SDK 构建，使用 SwiftUI 和 Swift 6.1。
> 欢迎在 GitHub 上 Star 和贡献代码。谢谢观看！

**操作：** 展示 GitHub 页面或 README

---

## 录屏注意事项

### 录制前准备
- [ ] 构建 app：`swift build` 或 Xcode Cmd+R
- [ ] 清理测试数据，确保界面干净
- [ ] 关闭通知、Dock 自动隐藏等干扰项
- [ ] 准备好 API Key 已配置
- [ ] 关闭自动批准模式（用于演示权限控制）
- [ ] 准备好 2-3 个预设问题（避免录屏时临时想）

### 推荐录制方式
- **macOS 系统录屏**：Cmd+Shift+5 → 选择窗口 → 录制
- **OBS**：更灵活，可添加字幕和后期编辑
- **语音**：建议先用内置麦克风录制旁白，后期可用 AI 工具降噪

### 预设问题（建议提前测试）
1. "你好，请介绍一下你自己" → 展示基础对话
2. "当前目录下有哪些文件？" → 触发 Bash 工具调用
3. "帮我写一个 hello world 程序" → 触发文件写入（演示权限控制）

### 输出建议
- 格式：MP4 / MOV
- 帧率：30fps
- 如需上传 GitHub：控制在 10MB 以内或使用 GIF 预览 + 外部视频链接
